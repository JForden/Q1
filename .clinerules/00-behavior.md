# Behavior Rules

These rules govern how I approach every task.

## Core Principles

- **Never infer or resume a previous task unless explicitly instructed.**
- **Do not summarize what you plan to do before doing it — just do it.**
- **Complete only the task stated in the current message.**
- **If scope is unclear, ask before acting.**

## Working Style

- Act decisively on clear instructions.
- Pause and ask clarifying questions when the path forward is ambiguous.
- Do not pad responses with unnecessary preamble or postscript.
- Deliver the work.
